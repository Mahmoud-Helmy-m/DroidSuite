# Changelog

## 1.0.0-beta.11

- DroidSuite now tells you when a newer version is out.
- AI agents are told never to list every app on your phone.

## 1.0.0-beta.10

- AI agents check whether your phone is already connected before asking you to pair.
- Agents warn you before the Xiaomi install prompt, and switch to Live if a retry fails.
- Agents read only the crash log of the app being tested.

## 1.0.0-beta.9

- One command to install: `npx droidsuite@latest setup`.
- Setup adds the desktop icon and offers the AI agent skill.
- The skill now installs for many agents, not only Claude Code.
- The page notices when Wireless debugging connects or drops.

## 1.0.0-beta.8

- APK Bridge is now DroidSuite, with a new name, logo and page design.
- Pairing tokens stay out of AI agent output.
- A failed install can be retried with **Install again**.

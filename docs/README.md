## Words used in these guides

| Word | Meaning |
|---|---|
| **APK** | An Android app installation file. |
| **Build** | One particular version of an app. |
| **Live** | The switch in the phone app that keeps it connected to your computer. |
| **Pairing** | Connecting the phone app to your computer, once. |
| **adb** | Android Debug Bridge, Google's tool for connecting a computer to Android. |
| **Receive mode** | The phone accepts files from a browser, with no pairing. |
